# Weekly summaries

Optional hand-written summaries shown under the notebook timeline's **View weekly summary** button.

Add one markdown file per week in this folder (any file name ending in `.md`, but this README is ignored). Weeks run Sunday to Saturday.

```md
---
week: 2026-07-19
---

This week we ran the first thiol-modified TMSDY gels. ...
```

- `week` is any date in that week, written `YYYY-MM-DD` with no quotes (the Sunday is clearest).
- The body is markdown (paragraphs, lists, **bold**).
- A week with no file here still gets an automatic summary built from its entries' Objectives. When a file exists, your text is shown first, followed by the list of that week's entries (without the automatic objectives).
